# AIXS

**Artificial Intelligence, Accessible.**

AIXS is an open research initiative exploring how frontier-class AI can move closer to low-end consumer-grade hardware by treating the full inference stack as one system: **Model × Harness × Software × OS × Hardware**.

The project is deliberately evidence-first: reproduce promising public work, establish transparent baselines, connect ideas across layers, and invent only what is missing.

## Current focus

**Mission 01 — MoE baseline**

Select a frontier-class open-weight Mixture-of-Experts model, establish a reproducible baseline on defined consumer hardware, then measure and optimize quality, throughput, latency, memory movement and efficiency across the five AIXS layers.

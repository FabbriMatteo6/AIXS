# Workloads

Store small, versioned, public workload definitions here. Large datasets stay external and must be referenced with source, revision and hash/provenance where practical.

Task-specific replay manifests, private source identifiers, historical solution reports, hidden acceptance tests and evaluator-only notes do not belong in this public candidate repository. Keep those materials in a private evaluator workspace and publish only a sanitized workload description when the fixture is ready for release.

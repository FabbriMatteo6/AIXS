# Workflow records

Use [README_AGENTS.md](../../README_AGENTS.md) for prompts and [TASK_LIFECYCLE.md](TASK_LIFECYCLE.md) for authoritative states.

- ACTIVE_TASK.md identifies one task.
- DOCUMENTATION_MAP.md filters durable updates.
- templates holds six artifact starters; reports are created when their role runs.
- tasks/active is current work, tasks/paused is unfinished work, tasks/completed is history.

Workflow reports describe delivery. Experiments record research measurements. Link them rather than duplicating evidence. Replay solutions and private evaluator material remain outside candidate workspaces.

# Hardware

## Scope

Consumer GPUs, Apple Silicon, integrated accelerators, heterogeneous/recycled machines, storage/memory systems, compute-in-memory and purpose-built local-AI hardware directions.

This pillar studies hardware. Machine descriptions used by experiments belong in the shared [`../../registry/hardware/`](../../registry/hardware/) registry.

## Current questions

- Which consumer hardware classes are limited by capacity, bandwidth, compute, I/O or software overhead?
- When is adding memory/storage more valuable than adding arithmetic throughput?
- Can heterogeneous devices cooperate efficiently enough to matter locally?
- Which memory-centric hardware ideas could change the local inference constraint surface?

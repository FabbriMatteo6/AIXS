# OS / System Layer

## Scope

Memory, I/O, scheduling, power management, device topology, process/runtime coordination and possible AI-tailored system layers across Linux, macOS and Windows.

## Current questions

- Can the OS expose better control over memory residency and storage-to-accelerator movement?
- How should inference scheduling interact with power and thermal limits?
- What topology information should runtimes use on heterogeneous machines?
- Which optimizations belong in user space, runtime space or the OS itself?

Experiments should state OS build/version and all relevant system tuning.
